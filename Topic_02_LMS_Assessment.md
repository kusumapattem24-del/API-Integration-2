# Topic 2 - N8N LMS Assessment
## Making Your First API Calls

## 1. Assessment Overview

This assessment evaluates your ability to execute REST API requests using GET, POST, PUT, PATCH, and DELETE methods in Postman and n8n. You will configure query parameters, headers, JSON request bodies, interpret HTTP status codes, and validate API responses.

## 2. Assessment Objective

Demonstrate your ability to build and test REST API requests using Postman and n8n HTTP Request nodes while correctly handling request methods, headers, JSON payloads, query parameters, and response validation.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topic 1.
- Install Postman and access an n8n instance.
- Have access to a public mock REST API.

## 4. Assessment Tasks

- Exercise 1 – Execute a GET request with query parameters.
- Exercise 2 – Create POST, PUT, PATCH, and DELETE requests using JSON payloads.
- Exercise 3 – Configure HTTP Request nodes in n8n for CRUD operations.
- Exercise 4 – Verify status codes, headers, JSON responses, and execution logs.
- Exercise 5 – Record a demo video, upload the workflow/source, and submit through the LMS.
